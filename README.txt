KBLAM84 — Google Images update
================================

1. Open your existing GitHub repository:
   https://github.com/eimantas42069-pixel/kblam84.github.io

2. Upload these files to the repository root (not a new subfolder):
   index.html
   leader-alus-5-1l.png
   leader.png
   sitemap.xml
   robots.txt

   If GitHub asks whether to replace an existing file, replace it.
   Leave your existing CNAME file alone. Do not remove the custom domain.
   The old leader.png is included to keep existing image links working.

3. Commit the upload and wait for GitHub Pages to deploy.
   Open https://kblam84.website/ and check that the page still looks right.
   The new image URL is:
   https://kblam84.website/leader-alus-5-1l.png

4. Use Google Search Console to verify the website if you have not already.
   Inspect https://kblam84.website/ and request indexing.
   You can submit https://kblam84.website/sitemap.xml in the Sitemaps section.
   Indexing and ranking are not guaranteed and can take days or weeks.

EDITING THE SITE
----------------
Spin speed: near the top of index.html, find --spin-speed: 500ms;
200ms = 5 rotations per second, 500ms = 2, 2000ms = one per 2 seconds.
The left bottles spin clockwise; the right bottles spin counterclockwise.

Google search title/description: edit <title> and <meta name="description">.
Discord description: edit <meta property="og:description">.
The visible KBLAM84 heading and Lithuanian text have not been changed.

No audio or new visual elements have been added. The original bottle image
is copied without resizing, redrawing, or recompression. The CSS layout is
unchanged from your uploaded index(1).html.
